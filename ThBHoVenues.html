หน้า Matching ทำงานยังไงHow a matching page works

  1. รวบรวมสินค้าจริงGather the real offerโปรแกรม ห้อง ราคา รูปจริงของร้านProgrammes, rooms, prices and real venue photos.
  2. ให้แต่ละอย่างมีบุคลิกGive each one a personalityชื่อ จุดเด่น และกลุ่ม MBTI ที่เข้ากันA name, strengths and the MBTI groups it suits.
  3. ลูกค้าตอบ 4 ข้อGuests answer 4 questionsจบใน 1 นาที ได้ 3 ตัวเลือกDone in a minute, three matches back.
  4. จองผ่าน LINEBook via LINEส่งถึงพนักงานพร้อมรหัสสินค้า · หน้าเว็บไม่เก็บข้อมูลลูกค้าHanded to staff with the item code. The page stores no guest data.
NTตัวอย่าง: ชอบห้องเงียบ คุยลึกe.g. quiet rooms, deep talk
NFตัวอย่าง: บรรยากาศอบอุ่น นวดอโรมาe.g. warm vibe, aroma massage
SJตัวอย่าง: โปรแกรมประจำ เวลาชัดe.g. regular programme, set times
SPตัวอย่าง: คืน theme เวทีโชว์e.g. theme nights, shows

ตัวอย่างการจัดกลุ่มเพื่อให้เห็นภาพ — ของจริงตั้งตามสินค้าของแต่ละร้านSample grouping for illustration — the real one is built from each venue's own offer.

กติกาที่ไม่ยืดหยุ่นGround rules — not negotiable

  • อายุ 20 ปีขึ้นไป20+ only — ทุกคนแสดงเอกสารยืนยันตัวตนก่อนถ่ายทุกครั้ง— everyone shows ID before every shoot.
  • ยินยอมเป็นลายลักษณ์อักษรWritten consent จากทุกคนในภาพ และระบุระดับความเปิดเผยก่อนเผยแพร่from everyone in frame, with the exposure level agreed before release.
  • สมัครใจ 100%100% voluntary — ปฏิเสธคู่ได้ทุกครั้ง ถอนตัวได้ตลอดโดยไม่ต้องอธิบาย— any match can be declined, anyone can leave at any time without explaining.
  • Matching ไม่ใช่บริการทางเพศMatching is not a sexual service — เป็นการจับคู่เพื่อใช้เวลาหรือทำงานร่วมกันในกรอบเวลา— it pairs people to spend time or work together within a set window.
  • ไม่ใช้ภาพใครโดยไม่ได้รับอนุญาตNo one's image without permission — persona ทุกตัวสร้างจากคนที่ยินยอมเท่านั้น— every persona is built only from people who agreed to it.
  • ต้นฉบับเก็บนอก platformOriginals kept off-platform — ไม่ฝากงานไว้กับ platform ใด platform เดียว— no work depends on a single platform.
